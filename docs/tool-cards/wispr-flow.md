# Wispr Flow

Wispr Flow is an AI dictation application that enters recognized speech into
other applications. This card records product-dependent facts. It is not an
endorsement and should be reviewed before use.

## Suitable role

Use Wispr Flow to capture a researcher's own spoken drafting, short memos, and
public or otherwise authorized text. Treat the recognized text as a derivative
that requires verification. Do not use it as an authoritative transcription
system for interviews or protected research audio without separate ethical,
contractual, and institutional approval.

## Current capabilities

As of the review date, the developer documents support for more than 100 languages
on macOS, Windows, iOS, and Android. Language detection operates by session rather
than by word. The documentation warns that rapid switching within one utterance
may not be recognized reliably and that non-English accuracy may differ from
English accuracy. The application can use active-window context to improve the
recognized text.

## Privacy and processing

The developer states that transcription is cloud processed. Its documentation
describes a Privacy Mode and an option to disable Private Cloud Sync. The current
security FAQ states that Privacy Mode is not enabled by default for standard and
trial accounts, and that dictation data may otherwise be used to improve models.
Context Awareness may transmit relevant text from the active application. The
service describes United States data processing and hosting.

Before use, verify the current account type, Privacy Mode, cloud-sync setting,
Context Awareness setting, retention terms, model-improvement terms, institutional
approval, and the sensitivity class of the material. A setting name is not proof
that a project is compliant.

## Project benchmark

Test each working language separately with a stable public or synthetic passage.
Include proper names, places, dates, acronyms, citations, specialized terms, and
the project's usual code-switching patterns. Record meaning-changing errors and
repeat the benchmark after material updates.

## Alternatives

Operating-system dictation, institutionally managed speech recognition, local
speech-recognition models, and manual capture may be preferable when privacy,
offline work, or reproducibility outweighs convenience.

# Historical Evidence Chain Lab

This companion lab carries the operational materials developed in the project
*Historical Evidence Chain: Salem Witch Trials Pilot* into *From Question to
Evidence*. It is the applied counterpart to the book chapter “Historical Sources
as Evidence.”

The book teaches the durable method. This lab supplies a bounded implementation:

- a research-design article;
- a document- and passage-level codebook;
- a parallel human coding form;
- versioned transcription, extraction, and audit prompts;
- Airtable and REDCap implementation specifications; and
- controlled vocabularies and provenance fields.

## Methodological role

The lab operationalizes the chain from source witness to transcription,
source-bound observation, declared normalization or inference, validation,
historical claim, and downstream audit. It is intended for teaching, protocol
design, and a future rights-cleared pilot. It does not contain archival images,
participant data, model outputs, adjudicated reference data, or empirical
findings.

The Salem materials are an extended specialist implementation, not the universal
case for the book. Readers should adapt the codebook only after documenting their
own period, language, record-production process, ethics, rights, and intended
claim types.

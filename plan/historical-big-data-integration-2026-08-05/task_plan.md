# Historical Big Data Integration Plan

## Goal

Combine the existing field guide with the Historical Evidence Chain project and
the two foundational papers without creating a competing book architecture.

## Work packages

- [x] Locate and audit the canonical book repository and historian project.
- [x] Read and extract the arguments and writing patterns of both papers.
- [x] Define the integrated scope, lifecycle, book-lab boundary, and bilingual
  publication strategy.
- [x] Import the Historical Evidence Chain materials with provenance and a rights
  boundary.
- [x] Revise the book contract, opening, bibliography, roadmap, and relevant
  chapters.
- [x] Run tests, content checks, and manuscript/site renders.
- [x] Preserve the pre-integration Vault state and synchronize the validated
  candidate.
- [x] Commit and push the integration branch.

## Release rule

Working Edition 0.2 remains unchanged. The integrated candidate may be rendered
and reviewed internally but must not be deployed as a public edition until the
manuscript gates pass and the Historical Evidence Chain license decision is
recorded.

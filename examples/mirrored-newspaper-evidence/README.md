# Mirrored Newspaper Evidence Example

This package accompanies the chapter “Mirrored Newspaper Evidence.” It contains
metadata, search decisions, short analytical descriptions, and stable links to
articles in the National Library of Israel. It does not contain newspaper scans.

`source-manifest.csv` records one row per article. `information_origin`
distinguishes local reporting, official bulletins, and reports dependent on
another newspaper. `verification` states whether the record was checked through
metadata, OCR, or the visible scan.

`event-crosswalk.csv` retains the Hebrew and Arabic records in separate columns.
`match_status` distinguishes confirmed events, probable matches, and
theater-level parallels.

`search-log.csv` preserves productive, negative, and false-positive searches.
Counts describe the National Library interface on 31 July 2026. They are not
claims about the full historical press.

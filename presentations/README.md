# Mirrored Newspaper Evidence Presentation

`mirrored-newspaper-evidence-he.pptx` is an editable Hebrew presentation of the
worked case in `content/10-mirrored-newspaper-evidence.qmd`.

The deck contains eleven slides and speaker-note source blocks. It uses only
original text and editable vector shapes. The build source is
`mirrored-newspaper-evidence-he.mjs`.

The final deck was rendered slide by slide, inspected as a montage and at full
size, and passed the presentation overflow test on 31 July 2026.

# From Question to Evidence

This repository contains the English discussion draft and pilot website for *From Question to Evidence: A Living Field Guide for Qualitative Research*, by Ami Pedahzur and Jonathan Grossman.

The project is under active development. The stable methodological core is written in Quarto Markdown. Generated documents and the static site are built from the same source. The legacy Notion export is deliberately excluded from this repository.
